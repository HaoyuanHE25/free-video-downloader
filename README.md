# 随下

在电脑或手机浏览器里粘贴公开视频链接，选一档清晰度保存到本地；同一条链接还能生成总结、字幕、思维导图和基于内容的追问。

不注册也能每天免费下载 3 次；注册用邮箱和密码，开通 ¥9.9 永久会员后不限次数。只处理你有权保存的公开内容，不提供平台账号代下。

产品范围见 [docs/需求分析.md](docs/需求分析.md)（第一期范围），实现与扩展点见 [docs/方案设计.md](docs/方案设计.md)，完成情况和边界见 [docs/项目总结.md](docs/项目总结.md)。

> 本项目的视频解析与下载能力基于开源工具 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 实现，随 `requirements.txt` 一并安装；本项目是其图形化/流程化封装之一，与各视频平台无任何隶属或合作关系。合法使用声明见文末「[合法使用声明](#合法使用声明)」。

## 能做什么

- **下载**：粘贴公开链接，解析标题、封面、时长和收拢后的清晰度，异步下载完成后由浏览器保存。抖音精选页、`/video/数字` 和短链都支持。
- **总结**：基于公开字幕生成大纲、要点和带时间点的章节，支持 Markdown 排版与复制。需要服务端配置 `DEEPSEEK_API_KEY`；未配置时下载和字幕照常可用，总结与问答会提示尚未配置，导图仍可用粘贴提纲生成。
- **字幕**：抓取平台字幕或引擎内置字幕，做语义分段，可下载 TXT、时间戳 TXT、SRT、VTT，也可复制。
- **导图**：由总结结构生成思维导图，支持全屏、20%–400% 缩放、拖动平移，以及 2x / 3x PNG 和 SVG 下载。
- **问答**：围绕同一条链接的字幕内容连续追问，回答走 Markdown 排版。
- **工作台布局**：宽屏（≥1024px）左侧为垂直标签栏并吸顶固定，右侧内容自适应；窄屏回退为顶部横向标签栏。
- **视觉**：Liquid Glass 风格——半透明毛玻璃容器、低饱和冷色渐变背景、柔和双层阴影、20px 卡片圆角，交互动画 150–240ms。

## AI 能力

本项目把 LLM 用在「字幕已就绪之后」的内容理解环节，四个功能模块的 AI 角色各不相同，核心下载链路保持零模型依赖：

| 模块 | AI 做什么 | 带来的价值 |
| --- | --- | --- |
| 总结 | 字幕 → 大纲 + ≤8 要点 + ≤12 个带时间戳章节，流式逐字呈现 | 不必通读视频：大纲首行数秒内可见，章节时间点可回跳原片 |
| 问答 | 限定在字幕内容内的多轮追问，Markdown 作答、带时间点引用 | 替代反复拖进度条确认细节；资料中没有的直说没有，不编造 |
| 导图 | 总结结构自动派生思维导图节点（前端确定性转换，不额外调用模型） | 从视频到结构图零手工；粘贴提纲也能用，AI 未配置时功能不缺失 |
| 字幕 | 不经模型改写，原文直接展示与导出 | 准确性敏感的内容不交给生成式模型 |

**实现路径**：带时间戳字幕行 → DeepSeek JSON 模式流式调用（`deepseek-v4-flash`，可换任何 OpenAI 兼容端点）→ 服务端结构校验（章节起点必须命中字幕、字段上限裁剪）→ SSE 逐段下发 → 前端渲染。技术选型依据、量化口径与传统方案对比见 [docs/方案设计.md](docs/方案设计.md)「AI 应用专项」一节。

**可靠性与成本**：未配置 `DEEPSEEK_API_KEY` 时下载 / 字幕 / 导图照常可用，仅总结与问答提示尚未配置——AI 是增强项而非单点故障；每次总结固定 1 次模型调用、输出长度被结构上限锁死，单条成本可预估。后续迭代方向（摘要缓存、ASR 兜底无字幕视频、RAG 长视频问答、多语言摘要）同样记录在方案设计文档中。

## 环境配置

按顺序完成以下 4 步。已在代码仓库根目录执行。

### 第 1 步：安装基础软件

| 软件 | 版本 | 安装方式 | 用途 |
| --- | --- | --- | --- |
| Python | 3.11+ | [python.org](https://www.python.org/downloads/) 或 `winget install Python.Python.3.12` | 后端服务 |
| Node.js | 20+ | [nodejs.org](https://nodejs.org/) 或 `winget install OpenJS.NodeJS.LTS` | 前端构建与开发服务 |
| ffmpeg | 4.x+ | Windows: `winget install Gyan.FFmpeg`；macOS: `brew install ffmpeg`；Ubuntu: `sudo apt install ffmpeg` | 合并分离的音视频流（高清档位必需） |

安装后用 `python --version`、`node --version`、`ffmpeg -version` 确认都能在终端执行。

> 没有 ffmpeg 时仍可保存单文件的清晰度和纯音频；没有 Node 时部分平台的清晰度档位会变少。抖音不需要用户提供 Cookie，精选页、`/video/数字` 和短链都可以直接解析，图文暂不保存。

### 第 2 步：安装后端依赖

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

依赖包含 FastAPI、uvicorn、解析引擎 yt-dlp、Stripe SDK、bcrypt 等。

### 第 3 步：安装前端依赖

```bash
cd web
npm install
```

### 第 4 步：配置 `.env`（可选）

在项目根目录创建 `.env` 文件。不配置任何内容也可以启动——下载、字幕、导图照常可用，会员支付走本地模拟通道：

```ini
# 总结/问答用，不配则这两个功能提示未配置
DEEPSEEK_API_KEY=sk-xxx

# 会员支付用，不配则走本地模拟收银台（详见 docs/会员与支付.md）
STRIPE_SECRET_KEY=sk_test_xxx
STRIPE_WEBHOOK_SECRET=whsec_xxx
```

完整环境变量说明见 [docs/会员与支付.md](docs/会员与支付.md) 第 7 节。

## 启动

开两个终端。

```bash
.venv\Scripts\activate
python -m uvicorn app.main:app --port 8000
```

```bash
cd web
npm run dev
```

浏览器打开 `http://localhost:5173`。Vite 会把 `/api` 代理到 `8000`。

只看构建结果时：

```bash
cd web
npm run build
python -m uvicorn app.main:app --port 8000
```

FastAPI 发现 `web/dist` 后会在 `http://127.0.0.1:8000` 同时提供页面和接口。

## 验收

```bash
pytest
```

当前 110 项通过。测试不访问真实视频站和模型服务，用假对象覆盖解析收拢、非法链接、字幕、总结流、导出格式、下载文件、认证、会员支付与会话持久化。

页面上再走一遍：

1. 空链接时，输入框下方出现「请先粘贴一条公开视频链接」。
2. 输入 `http://127.0.0.1/a` 或不是链接的文字，出现拒绝原因，且不开始下载。
3. 粘贴一条短的公开链接，确认标题和 1080p / 720p / 480p / 仅音频等档位，切换选中态。
4. 点「保存到本地」，视频条内出现进度；完成后按钮变为「再次下载」，浏览器开始保存文件。
5. 解析成功后，工作台出现「总结 / 字幕 / 导图 / 问答」；逐项切换，确认内容只出现在对应面板。
6. 字幕面板可下载 TXT、时间戳 TXT、SRT、VTT；导图可全屏、缩放、拖动，并下载 PNG / SVG；问答可连续追问。
7. 窗口拉宽到 1024px 以上时标签栏在左侧垂直排列并吸顶；缩到手机宽度时回到顶部横向标签，页面不横向溢出。

会员卡上的「即将开放」不会扣费。批量下载、字幕翻译都还没做，登录、每日配额与会员支付已上线（支付未配密钥时走本地模拟通道）。
