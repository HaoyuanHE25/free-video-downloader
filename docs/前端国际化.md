# 随下：前端国际化（i18n）接入规范

前端已接入 `vue-i18n`（Composition API 模式），支持简体中文与英文实时切换。本文说明语言包结构、新增文本的接入步骤、服务端文案的翻译方式与自检清单，后续所有涉及界面文案的改动都按本文执行。

## 1. 技术方案与目录

| 项 | 说明 |
| --- | --- |
| 方案 | `vue-i18n` v11，`legacy: false`，组件内统一用 `useI18n()` |
| 默认语言 | `zh-CN` |
| 兜底语言 | `zh-CN`（英文缺失的 key 自动回落中文，不中断渲染） |
| 缓存 key | `localStorage` 的 `sx.locale.v1` |
| 切换入口 | 顶栏右侧「中文 / EN」分段按钮，窄屏也保留 |

```
web/src/i18n/
├── index.js              # 创建 i18n 实例、语言探测、setLocale、同步 <html lang> 与标题
├── messages.js           # 服务端中文提示 → key 的映射，renderMessage / stageMessage
└── locales/
    ├── zh-CN.json        # 中文语言包（基准，新增 key 先写这里）
    └── en.json           # 英文语言包（与中文保持同一套 key）
```

`web/src/main.js` 里通过 `createApp(App).use(i18n)` 挂载，全站共享同一个全局作用域。

## 2. 语言包结构

语言包按界面模块分顶层命名空间，二级 key 用驼峰短语。`zh-CN.json` 与 `en.json` 的 key 必须完全一致。

| 命名空间 | 覆盖范围 |
| --- | --- |
| `meta` | 页面标题、meta description（切换语言时同步到 `document`） |
| `common` | 品牌名、关闭、复制失败等跨模块文案 |
| `stage` | 流式任务的进度文案（读取字幕、生成摘要等） |
| `app` | 首屏标题、副标题、三项说明 |
| `notice` | 全局浮层提示（支付、重置密码等） |
| `error` | 前端自己产生的错误提示 |
| `server` | 服务端返回的中文提示的翻译结果 |
| `header` / `footer` | 顶栏与页脚 |
| `feature` / `highlights` / `member` | 官网介绍区与会员卡 |
| `parse` / `result` | 解析输入框、结果卡片与下载 |
| `workspace` | 工作台标签 |
| `summary` / `subtitle` / `mindmap` / `qa` | 四个功能面板 |
| `auth` / `reset` | 登录注册弹窗、重置密码弹窗 |

## 3. 新增文本的标准步骤

1. 在 `web/src/i18n/locales/zh-CN.json` 找到对应命名空间，新增 key：
   ```json
   {
     "summary": {
       "openSource": "查看字幕来源"
     }
   }
   ```
2. 在 `web/src/i18n/locales/en.json` 的同一路径补英文，key 名称保持完全一致。
3. 在组件里用 `t('summary.openSource')` 渲染，不要写死中文或英文。

带变量的文案用命名占位符，不要用字符串拼接：

```json
{
  "result": {
    "savingPercent": "正在保存 {percent}%"
  }
}
```

```vue
{{ t('result.savingPercent', { percent: 42 }) }}
```

## 4. 组件内用法

### 4.1 模板中的静态文本

```vue
<script setup>
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
</script>

<template>
  <h2>{{ t('summary.outline') }}</h2>
</template>
```

### 4.2 脚本里的列表与计算属性

数组、对象里的文案要放进 `computed`，这样切换语言时会重新计算：

```js
const tabs = computed(() => [
  { id: 'summary', label: t('workspace.summary') },
  { id: 'qa', label: t('workspace.qa') },
])
```

在脚本中访问 `computed` 记得加 `.value`（如 `tabs.value.length`），模板中则无需。

### 4.3 属性与可访问性文案

`placeholder`、`title`、`aria-label` 同样是展示文本，必须走 `t()`：

```vue
<input :placeholder="t('qa.placeholder')" />
<button :aria-label="t('common.close')">×</button>
```

### 4.4 错误提示的状态存储

错误状态里存 **key**（如 `'error.passwordTooShort'`），不要存已翻译的句子，否则切换语言时旧提示不会更新。渲染时统一交给 `renderMessage()`：

```js
error.value = 'error.passwordTooShort'
```

```vue
<p v-if="error">{{ renderMessage(error) }}</p>
```

## 5. 非组件模块

`format.js`、`api.js` 这类纯 JS 模块没有组件上下文，使用全局实例：

```js
import { i18n } from './i18n/index.js'

i18n.global.t('result.unknownSize')
```

`api.js` 里的兜底错误直接抛出 key（`'error.generic'`），由展示层翻译。

## 6. 服务端文案

后端不感知语言，`detail`、SSE 事件里的 `message` 都是中文。前端在展示边界翻译，不在后端做多语言：

- 所有提示统一用 `renderMessage()` 渲染，它按以下顺序处理：
  1. 命中语言包 key → 直接翻译；
  2. 命中 `messages.js` 的中文映射表 → 翻译成当前语言；
  3. 都不命中 → 原样显示（如视频标题等业务数据）。
- 新增后端提示时，在 `web/src/i18n/messages.js` 的 `SERVER_MESSAGES` 里加一行「中文原文 → `server.xxx`」，并在两个语言包里补 `server.xxx`。
- 带数字的提示用 `SERVER_PATTERNS` 正则匹配，例如「文件超过约 500MB」→ `server.fileTooLarge`，数字通过 `{size}` 参数传入。
- 流式进度事件不要直接展示 `data.message`，用 `stageMessage(data.stage, data.message)` 先转成 `stage.xxx`，只在未知 stage 时才回退到后端文案。

## 7. 语言切换与持久化

```js
import { LOCALES, currentLocale, setLocale } from '../i18n/index.js'

setLocale('en')        // 写入 localStorage，更新 <html lang>、标题与描述
currentLocale()        // 读取当前语言（放在 computed 里可响应变化）
```

- 首次进入的优先级：`localStorage` 的 `sx.locale.v1` → 浏览器语言（`zh*` / `en*`）→ `zh-CN`。
- 切换即时生效，无需刷新；`document.documentElement.lang`、`document.title`、`meta[name=description]` 同步更新，便于搜索引擎与读屏软件识别。
- 新增语言只需在 `LOCALES` 里加一项，并在 `locales/` 增加同名 JSON、在 `i18n` 的 `messages` 中注册。

## 8. 不应翻译的内容

- 品牌名「随下」（语言包里两个语言都保持原样，便于统一改）。
- 用户数据与服务端业务数据：视频标题、频道名、字幕正文、AI 生成的总结与回答。
- 文件名前缀属于界面文案，需要翻译（`subtitle.filePrefix`、`mindmap.filePrefix`）。

## 9. 布局与自检清单

英文普遍比中文长，改动文案后按下面清单自检：

- [ ] 两种语言下均无横向滚动条，640px 以下窄屏正常。
- [ ] 按钮、标签、统计胶囊不被撑破或截断（必要时调 `max-w`、`min-h` 或用 `flex-wrap`）。
- [ ] 顶栏在窄屏下仍能同时容纳品牌、语言切换与登录/退出。
- [ ] 弹窗标题、提示语换行后不遮挡关闭按钮。
- [ ] 表单 `placeholder` 与提交按钮文案切换后不溢出输入框。
- [ ] 切换语言时，正在展示的错误、进度、上传提示会同步更新（说明存的是 key 而非句子）。
- [ ] 刷新页面后语言保持上次选择。
- [ ] `npm run build` 通过。
