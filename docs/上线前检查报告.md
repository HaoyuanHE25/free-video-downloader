## 3. 核心业务流程验证

- **解析与下载**：参数校验（长度上限、格式）、非法链接/内网地址拒绝、配额原子计数与失败返还（`app/main.py`）、任务文件下载后即清理，逻辑闭环。
- **账号与会员**：注册/登录/重置有格式校验、频控（60s 冷却）与失败锁定（5 分钟 8 次）；会话 7 天滚动续期；会员只由支付回调开通；幂等事件 ID。
- **总结/字幕/导图/问答**：SSE 流式接口客户端实现稳健（CRLF 处理、缓冲解析、错误帧不中断、abort 安全）；并发信号量与排队上限齐全。
- **i18n**：本地缓存 → 浏览器语言 → 默认中文的检测链路；`<html lang>`/标题/描述随语言同步；映射表覆盖全部服务端文案（本次补齐后）。
