# 随下：需求分析（第一期）

本文给后续改功能的人和 AI 使用，记录的是**第一期**的范围快照：「粘贴公开链接 → 看清标题和清晰度 → 保存到本地」。后续第二、三期已在其上补齐视频总结、字幕提取与下载、思维导图、问答，以及左侧垂直标签 + Liquid Glass 的工作台。现状、接口和视觉约定以 [方案设计.md](方案设计.md) 与 [项目总结.md](项目总结.md) 为准；本文「明确不做」和「后续方向」里的条目，凡与那两份文档冲突，以那两份为准。

## 谁在用

用电脑或手机浏览器的人。他们已经能打开一条公开视频，但平台自己的下载入口不够用：没有想要的清晰度、只能在 App 里保存、换一台设备就找不到文件，或者根本不提供保存。

第一期不区分登录用户和访客。所有人用同一套限额。

## 要解决的问题

平台下载通常绑在自己的 App、会员或清晰度策略上。用户要的是一件更小的事：

1. 复制浏览器里的公开链接。
2. 看到标题、平台和少数几档清晰度，而不是一长串编码格式。
3. 选一档，把文件保存到自己的电脑或手机。

手机浏览器必须能走完这条路径。保存动作要触发浏览器下载，不能只在桌面端可用。

## 第一期必须做到

- 单页工具。打开就能看到标题、一条链接输入框和「解析」。
- 只接受公开的 `http` / `https` 链接。解析出标题、封面、时长、平台名，以及收拢后的清晰度。
- 清晰度最多四档：最佳 1080p、最佳 720p、最佳 480p、仅音频。默认选中不超过 1080p 的最佳一档。
- 下载异步进行，同一张卡片上能看到进度；完成后浏览器开始保存，按钮变为「再次下载」。
- 电脑宽屏和手机窄屏都能用。窄屏单列，主要按钮高度至少 44px。
- 页面下方说明免费档每天 3 次下载，会员档展示不限次数与更高限额，价格 ¥9.9 一次性买断。
- 页脚写明版权边界：仅供学习，只下载你有权保存的内容；不接收平台账号 Cookie。

## 明确不做

这些不在**第一期**的接口、数据库和页面行为里。其中视频总结、字幕提取与下载、思维导图、问答、登录、支付与数据库已在后续迭代实现；批量链接、字幕翻译仍未做。

- 视频总结、字幕提取、字幕翻译
- 注册、登录、Cookie 登录、代用户登录平台（邮箱密码登录已在第四期实现，见 [会员与支付.md](会员与支付.md)）
- 数据库、订单、微信支付、Stripe 或任何真实扣费（SQLite 与 Stripe 一次性付款已在第四期实现）
- 批量链接、播放列表整表下载
- 接收或转发平台 Cookie、账号密码
- 绕过加密、付费墙、私密或仅会员可见的内容
- 修改上游解析库的提取器源码，或把它的源码复制进仓库

会员卡上的批量链接、字幕翻译只是预告，按钮不能发起支付。

## 版权与封号

- 只面向用户有权保存的公开内容。页面和接口都不提供「登录后代下」。
- 不收集平台 Cookie，也不提供用户名、密码字段。避免把用户的平台账号交给这台服务器。
- 不把下载器当成内网客户端。拒绝本机、内网和链路本地地址，包括域名解析到这些地址的情况。
- 第一期不保存用户身份。临时视频文件在回传给浏览器后删除，重启进程后任务清空。

## 怎样算第一期做完

- 非法链接和内网地址会被拒绝，并在页面上用简短中文说明原因。
- 解析结果被收成少数清晰度，而不是把解析引擎的原始格式列表原样丢给页面。
- 用户能在页面上选清晰度、看到进度，并得到一个浏览器可保存的文件。
- 手机宽度下页面是单列，按钮和文字不挤出屏幕。
- 自动化测试不依赖真实长视频：用假的解析引擎对象覆盖解析收拢、拒绝非法链接、任务完成后取文件。
