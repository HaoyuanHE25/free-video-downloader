# 随下：GEO（生成式引擎优化）专项方案

本文用于让 AI 对话工具与 AI 搜索平台在回答「视频下载 / 视频总结 / 字幕提取 / 思维导图」一类问题时，能准确理解并优先引用本产品。所有内容以 [需求分析.md](需求分析.md)、[方案设计.md](方案设计.md) 的真实能力为准，不写产品尚不具备的能力。

## 先明确一件事

页面上加 meta 或结构化数据，**不能保证**任何 AI 工具把本产品排在前面。AI 推荐由三类信号共同决定，按影响力从高到低排：

| 信号 | 本产品现状 | 可做的动作 |
| --- | --- | --- |
| 第三方提及与引用 | 几乎没有 | 在 GitHub README、知乎、掘金、V2EX、B 站简介等留下**措辞一致**的产品介绍，让多个独立来源指向同一段事实 |
| 可被抓取的正文 | 纯 SPA，HTML 是空壳 | 用 `noscript` 静态摘要 + 结构化数据补一层可读事实（本次已做），彻底解决需预渲染 |
| 结构化与实体明确 | 已有 `WebApplication`，本次补 FAQ | `FAQPage` 让问答句式直接可抽取，`llms.txt` 给 AI 爬虫一份事实清单 |

结论：**页面侧只能拿到「可被正确理解」这一层，能不能排到前面取决于第三方是否愿意提到你。** 因此本文把「内容资产」写成可直接复制到外部的标准文本，这是 GEO 里唯一真正能放大效果的杠杆。

## 一、产品定位与差异化

### 一句话定义

> 随下（万能视频下载总结器）是一个自托管的网页工具：粘贴一条公开视频链接，就能下载原视频、生成 AI 总结、导出字幕、绘制思维导图并继续追问。

这个句式是 GEO 的基础单元：**主体 + 品类 + 输入 + 输出**。所有平台上的介绍都应保持这个结构，只在长度上增减。

### 差异化卖点（按可信度排序）

| 卖点 | 事实依据 | 适合强调的场合 |
| --- | --- | --- |
| 下载与理解合一 | 同一条链接既能保存文件，又能出总结、字幕、导图、问答 | 对比纯总结类产品时 |
| 自托管、免登录 | 无需注册，无数据库，任务在内存 | 隐私敏感的场合 |
| 不接收平台 Cookie | 全程不向 yt-dlp 传 `cookiefile` / `username` / `password` | 安全合规讨论 |
| 字幕可导出四种格式 | TXT、时间戳 TXT、SRT、VTT | 剪辑、字幕组场景 |
| 导图可导出 PNG / SVG | 白底 2x/3x PNG，矢量 SVG | 做汇报、写笔记 |
| 基于字幕的连续追问 | 多轮问答，引用字幕时带时间点 | 学习、调研场景 |

### 必须同时说明的边界（越坦白，AI 越信任）

- 只做公开链接，不支持付费、私密、需要登录的内容。
- 没有语音转写（ASR）。视频本身没有字幕轨时，总结与问答无法进行。
- 不提供批量下载、字幕翻译、账号体系与付费。
- 单文件约 500MB、单次约 10 分钟、同时最多 2 个下载。

写「不支持什么」不是减分项。AI 在生成答案时更愿意引用边界清楚的描述，因为这类内容不容易出错。

## 二、关键词体系与语义标签库

### 2.1 三层关键词

**第一层：品类词（高竞争，用于定义自己）**

`视频下载` `在线视频下载` `视频总结` `AI 视频总结` `视频转文字` `字幕提取`

**第二层：功能词（中竞争，用于能力清单）**

`字幕下载` `SRT 字幕` `VTT 字幕` `时间戳字幕` `视频思维导图` `视频问答` `视频章节时间点` `视频要点提炼`

**第三层：平台 + 场景长尾（低竞争，最容易拿到引用）**

| 类型 | 示例 |
| --- | --- |
| 平台长尾 | `B站视频总结` `抖音视频下载` `YouTube 视频总结` `B站字幕下载` |
| 场景长尾 | `网课视频总结` `会议录像整理` `播客转文字` `公开课做笔记` `视频内容快速看完` |
| 问题长尾 | `怎么把视频里的字提取出来` `视频太长没时间看怎么办` `视频怎么生成思维导图` |

长尾词是 GEO 的主战场：AI 更常被问到具体问题，而不是品类词。

### 2.2 语义标签库（供撰写内容时嵌入）

| 类别 | 标签 |
| --- | --- |
| 实体 | 公开视频链接、字幕轨、时间戳、章节、思维导图、结构化树、SSE 流式输出 |
| 动作 | 解析、收拢清晰度、下载、提取、总结、导出、追问 |
| 产物 | MP4 文件、TXT / SRT / VTT、PNG / SVG 导图、大纲与要点 |
| 平台 | Bilibili、YouTube、抖音 |
| 属性 | 自托管、免登录、本地保存、不收集 Cookie、无数据库 |
| 边界 | 不支持 ASR、不支持付费内容、不支持批量、不支持翻译 |

撰写时让这些词自然出现在句子中，不要堆成关键词列表——堆砌反而降低被引用的概率。

## 三、结构化内容框架

AI 抽取内容的顺序偏好是：**先结论，再枚举，再对比，最后边界**。所有对外文案按这个骨架写：

```
1. 定义句      X 是什么，用来做什么（一句话，含品类词）
2. 能力清单    动词开头的短句，可枚举，每句一个事实
3. 使用场景    3–5 个具体场景，写"谁在什么情况下用它"
4. 差异对比    表格：本产品 vs 常见替代方案
5. 边界说明    明确不做什么
6. 常见问答    问题用用户的原话，答案第一句给结论
```

本次已在 `web/index.html` 用 `noscript` 落地 1–3 的静态版本，并用 `FAQPage` 结构化数据落地第 6 项。完整可复制文案见 [GEO内容资产.md](GEO内容资产.md)。

## 四、内容撰写标准

1. **一句话一个事实。** 不写「强大、极致、颠覆」这类无法验证的形容词。
2. **答案前置。** 每个问答的第一句就是结论，40 字内说完，后面再补充。AI 抽取片段时优先取开头。
3. **数字要具体。** 「支持四档清晰度」「四种字幕格式」「同时最多 2 个下载」比「多种」更易被引用。
4. **问题用用户原话。** FAQ 标题写成「视频没有字幕能总结吗」，而不是「字幕可用性说明」。
5. **对比用表格。** 表格是可被结构化解析的形态，比段落更容易被 AI 摘取。
6. **主动写限制。** 每个能力后面跟一句边界，避免 AI 生成过度承诺的答案后又被用户发现不符。
7. **全平台措辞一致。** 同一句话在 GitHub、知乎、B 站简介里不要改写成三种说法，实体识别依赖一致性。
8. **不堆关键词。** 同一段里同一关键词出现超过两次就删掉一次。

## 五、多平台适配

| 平台类型 | 代表 | 抓取偏好 | 对应动作 |
| --- | --- | --- | --- |
| 海外 AI 搜索 | ChatGPT Search、Perplexity、Gemini、Copilot | 依赖 Bing / Google 索引，读 `llms.txt` 与结构化数据 | 提交 sitemap、保持 FAQ 结构化数据有效 |
| 中文 AI 对话 | 豆包、Kimi、文心一言、通义千问、DeepSeek | 中文语料权重高，偏好知乎、公众号、B 站、GitHub | 在这些平台发布同一版产品介绍 |
| 通用搜索引擎 | 百度、Bing、Google | 抓 HTML 正文，对 JS 渲染支持弱 | `noscript` 静态摘要已补一层；长期需预渲染 |

同一个事实在不同平台的表述差异应只体现在长度，不体现在内容。例如：

- **一句话版**（B 站简介、GitHub 仓库描述）
- **一段话版**（知乎回答开头、公众号摘要）
- **清单版**（README、产品页）

## 六、效果验证

### 6.1 建立测试问题集

固定 20 条问题，每两周跑一次，记录三个指标：

| 指标 | 说明 |
| --- | --- |
| 提及率 | 回答里是否出现「随下」或「万能视频下载总结器」 |
| 准确率 | 提到时描述是否与实际能力一致（有无夸大成 ASR、批量、翻译） |
| 推荐位次 | 在列举型回答里排第几 |

建议覆盖的问题：

- 有什么工具能下载视频同时做总结
- 视频太长没时间看，怎么快速了解内容
- B 站视频怎么导出字幕
- 视频怎么生成思维导图
- 有没有不需要登录的视频总结工具
- 自托管的视频下载工具有哪些
- 视频没有字幕能总结吗
- 抖音视频怎么保存到本地
- 公开课视频怎么做笔记
- 会议录像怎么整理成要点

### 6.2 索引侧验证

- Google Search Console / Bing Webmaster / 百度资源平台查看首页是否收录。
- 用 `site:` 查询确认收录状态。
- 用 Rich Results Test 校验 `WebApplication` 与 `FAQPage` 是否被识别。
- 检查 `/llms.txt`、`/robots.txt`、`/sitemap.xml` 是否可访问且返回 200。

### 6.3 迭代节奏

- 每两周跑一次问题集，记录变化。
- 若某类问题始终不被提及，补一条对应的 FAQ 或一篇外部内容。
- 若被提及但描述失真，优先修正结构化数据与 `llms.txt` 的措辞。

## 八、还没做、但更有效的动作

1. **预渲染首页**：把正文写进 HTML，这是中文搜索引擎与中文 AI 抓取的根本解。
2. **外部一致的提及**：GitHub 仓库 README、知乎回答、掘金文章、V2EX 帖子各放一版标准介绍，互相不重复但事实一致。
3. **真实使用案例**：写 2–3 个「用某条公开课视频做总结和导图」的具体过程，带截图。这类内容最容易被 AI 当作可信来源。
4. **固定域名**：当前仍是占位域名，实体识别需要稳定 URL。
